5. 功能原型展示

以下原型基于 Corporate 8-Bit 设计系统，模拟微信H5端（480px宽度）实际效果

P0 MVP 模块一：像素捏人换装

用户创建专属像素Avatar，选择职业主题服装和配饰。基础款免费；限定款通过任务解锁。 技术方案：Canvas像素绘制引擎（参考Piskel），分层渲染（身体/服装/配饰）。

像素捏人实验室 (EN)
像素捏人实验室 (CN)

P1 模块二：我的像素工位

拖拽像素家具/摆件装饰个人工位桌面和背景。状态展示："搬砖中🟢"、"摸鱼中🟡"、"开会中🔴"。 搭子送的礼物自动摆放在工位上，带有社交属性。

My Pixel Desk (EN)
我的像素工位 (CN)

P0 MVP 模块三：云端工友村

选择一个像素场景作为"云办公室"，搭子的Avatar在场景中可见、可移动、可交互。 支持戳一戳、请喝茶、传纸条等实时互动，WebSocket实时推送。

Cloud Co-worker Village (EN)
云端工友村 (CN)

P1 模块四：匿名茶水间

匿名投稿职场"神人神事"，像素漫画风格的内容流。支持投稿、互动（支持/爆笑/分享）。 AI+人工双重审核确保合规。

Anonymous Tea Room (EN)
匿名茶水间 (CN)

P0 MVP 模块五：AI吐槽搭子

AI NPC "老汪"——35岁，10年职场老油条，说话毒舌但靠谱。 核心能力：无脑接吐槽→理解情绪→给出共鸣→生成梗图。 技术：LLM API + System Prompt(人设) + 记忆系统。

AI吐槽搭子「老汪」 (CN)
AI Roast Buddy "Old Wang" (EN)

6. 设计系统：Corporate 8-Bit

设计理念：90年代办公软件与16-bit RPG美学的融合。将枯燥的工作任务转化为"任务/quests"， 将数字存在变成生动的游戏世界。风格关键词：高对比度 / 粗边框 / 像素风 / 等距偏移。

主色调

字体系统

Space Grotesk — 标题

Inter — 正文

SPACE MONO — 标签/UI

间距系统

基于 4px 像素网格

4px / 8px / 16px / 32px

设计原则

原则说明
形状严格 0px 圆角（Sharp），任何"曲线"需用阶梯式4px/8px块构建
纵深通过粗边框和等距偏移而非柔和阴影表达层级
Raised State元素使用 4px 底部+右侧边框模拟3D像素挤出
Pressed State元素整体向右下偏移 2px，模拟物理按压
图标16x16 或 24x24 像素网格，无反锯齿，线条清晰
列表分隔2px 虚线分隔（交替2px黑+2px透明），保留复古UI感

7. 技术架构

前端渲染引擎

Phaser.js 3.x

2D游戏框架成熟、Tiled地图原生支持、插件生态丰富

实时通信

Colyseus + WebSocket

专业多人游戏状态同步、房间管理、官方Phaser客户端示例

业务后端

Node.js / Python

Express/Fastify 或 FastAPI，按团队技术栈决定

AI服务

LLM API + SD

Claude/OpenAI/DeepSeek + Stable Diffusion(ControlNet)

微信集成

JS-SDK + 服务号

OAuth登录、模板消息、分享、支付

数据存储

MySQL + Redis

关系型用户数据 + 实时状态缓存 + OSS资源存储

技术难点与解决方案

难点描述解决方案
微信H5 Canvas性能微信内置浏览器对WebGL支持有限Phaser CANVAS模式；像素风天然低像素数；懒加载
实时多人状态同步多人Avatar位置/动作低延迟同步Colyseus状态同步+插值；房间上限控制
AI角色记忆AI搭子需记住用户信息向量化存储；对话摘要压缩；关键信息提取

8. 产品路线图

Phase 1 · 0-3月

MVP — 「能搭上线」

  • ✓ 微信OAuth登录
  • ✓ 像素捏人（5套职业装扮）
  • ✓ 添加搭子（微信分享邀请）
  • ✓ 虚拟办公室（格子里场景）
  • ✓ 戳一戳 / 请喝茶（2-3种互动）
  • ✓ 实时文字聊天
  • ✓ AI吐槽搭子（单NPC）
  • ✓ 工位基础装扮（5-10个摆件）
Phase 2 · 3-6月

社交深化 — 「玩在一起」

  • ✓ 多场景切换（5+场景）
  • ✓ 摸鱼小游戏（2-3个）
  • ✓ 像素日记 + 海报生成
  • ✓ AI搭子周报
  • ✓ 工位虚拟商店（含付费）
  • ✓ 成就系统 + 等级体系
  • ✓ AI职场导师
Phase 3 · 6-12月

社区扩展 — 「圈子发酵」

  • ✓ 匿名茶水间（公司圈）
  • ✓ AI像素漫画/八卦小报
  • ✓ 足迹地图
  • ✓ 多人办公室（10人群组）
  • ✓ AI场景生成器
  • ✓ 品牌联名装扮
Phase 4 · 12-24月

规模化 — 「生态构建」

  • ✓ 开放平台（第三方装扮）
  • ✓ 企业版（团建/入职场景）
  • ✓ 用户自定义NPC人设
  • ✓ 内容IP化（漫画/表情包）
  • ✓ 小程序 + 独立App

10. 风险评估

风险概率影响应对策略
冷启动失败高致命AI搭子兜底 + 种子用户定向招募 + 搭子周报病毒传播
微信生态封禁中高内容审核 + 先审后发 + 备选小程序 + 独立App
AI对话合规中高AI输出过滤 + 人工抽检 + 用户协议边界
社交关系难沉淀高中搭子等级+成就绑定 + 共同记忆（周报/日记）+ 微信模板消息召回
大厂抄袭中中快速迭代壁垒 + AI+像素双特色 + UGC沉淀
用户留存低中高AI日常推送 + 每日签到任务 + 小游戏单人模式

合规清单

  • □ 微信OAuth最小化信息收集（仅OpenID+昵称+头像）
  • □ 用户隐私协议 + 用户服务协议
  • □ AI生成内容标识（"本内容由AI生成"）
  • □ 匿名社区AI+人工内容审核机制
  • □ ICP备案 / 网络文化经营许可证
  • □ 用户数据存储境内（个人信息保护法）
